个人工作台 V1.1.1 · 智能安全同步版

新增功能：
1. 设置页新增“智能安全同步”中心。
2. 一键判断本机与云端版本，自动选择上传、下载或保持不变。
3. 本机数据修改后自动标记“本机有新内容”。
4. 可选择开启自动同步，修改后约 4 秒自动加密上传。
5. 本机和云端同时变化时停止自动覆盖，并要求人工确认。
6. 上传、下载前继续保留本机安全快照。

GitHub 根目录上传文件：
- app-v111t.js
- v111t.html
- sw-v111t.js
- index.html
- manifest.json

测试重点：
1. 打开“设置”，点击“立即安全同步”，应提示本机与云端一致。
2. 新增一条记录，再回到设置，应显示“本机有新内容”。
3. 再次点击“立即安全同步”，云端版本应增加 1。
4. 开启自动同步后新增记录，约 4 秒后应自动完成同步。
