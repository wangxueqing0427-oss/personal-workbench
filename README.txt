个人工作台 V0.4.1 — 真实口语识别修正版
========================================

本次只修“随口记识别”，不堆新功能。

重点修复：
1. “北医三院打车92元，有票，公司报销，主任说10月底可能增加光纤用量”
   应拆成：
   - 财务：公司垫付 / 92元 / 已有发票 / 待报销
   - 未来雷达：光纤用量可能增加 / 10月底跟进
2. 增强医疗工作关键词：医院、主任、科室、维保、耗材、光纤、上量、用量、采购、需求等。
3. 增强未来商机判断：可能、预计、后续、月底、增加、上量、需求、采购、跟进等。
4. “热水器师傅已上门维修，问题马上解决”等家庭维修语句自动进入生活板块。
5. 财务记录标题与商机标题尽量拆开，不再整句重复。
6. 保留 V0.4 全部数据结构、Face ID/Passkey、资料库和备份功能。

建议覆盖 GitHub 仓库中全部 6 个同名文件后提交，避免 Service Worker 缓存旧版本。
