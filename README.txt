个人工作台 V0.4 — 智能随口记版
====================================

本版核心升级：
1. 首页“随口记”升级为“智能随口记”
2. 输入一句自然语言后，本机规则先自动判断：
   - 财务 / 报销
   - 工作事项
   - 未来商机 / 未来雷达
   - 生活事项
   - 学习记录
   - 无法判断时进入收件箱
3. 一句话可以拆成多条记录
4. 自动整理后先进入“确认页”
5. 用户可修改金额、项目、日期、分类、报销状态等
6. 确认后再真正入库
7. V0.3 原有 Passkey / Face ID、本机资料库、数据备份继续保留
8. 会自动尝试继承 V0.3 本机数据

测试建议：
- “今天去海淀医院打车86元，有票，公司报销”
- “石景山医院11月可能有维保需求，10月底联系张主任”
- “孩子下周五开家长会”
- “353今天学了40分钟”
- “今天去北医三院打车92元，有票，主任说10月底可能增加光纤用量”

说明：
当前“智能”使用本机规则，不调用外部 AI，因此：
- 无 API Key
- 无额外费用
- 数据不上传外部 AI
- 能力有限但适合先测试交互流程

下一阶段：
如果 V0.4 的交互体验确认顺手，再接安全 AI 接口，让自然语言识别更准确。
