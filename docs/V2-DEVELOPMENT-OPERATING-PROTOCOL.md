# V2 DEVELOPMENT OPERATING PROTOCOL

版本1.0，2026-11-01。适用于安全候选及独立开发分支；不授予生产、Cloudflare或真实资料操作权限。

## 三方职责

|角色|负责|边界|
|---|---|---|
|用户|业务优先级、真实iPhone最终体验、账号本人验证、费用/敏感资料/推送/合并/发布授权|不承担中间技术排错|
|Codex|核实代码、最小实现、合成测试、排错、证据、提交及获准的Draft PR|不能自行取得真实数据权限，不能冒充ChatGPT独立审查|
|ChatGPT|独立审查需求、完整差异、机器证据、风险及放行建议|审查建议不等于用户合并/部署批准|

## 开发、测试、排错、验收流程

1. **接收**：确定单一验收目标、文件范围、禁止动作、停止条件。读AGENTS/CURRENT/ROADMAP，核对HEAD与工作区，只查相关依赖及可信历史。
2. **隔离**：从批准完整SHA建独立分支；保留未知变更，不reset/clean真实资料，不移动候选或main引用。所有权问题只用核实目录的单次safe.directory，不改全局配置或ACL。
3. **实施**：先确定最小方案，复用代码和测试；不搭新架构、不顺便加功能。权限、软件安装、付费、云资源和真实资料依授权处理。
4. **测试**：按风险矩阵执行针对性检查。未受影响的可信结果只引用，不重复运行；日志脱敏。数据安全改动必须覆盖完整相关风险域，不等于无差别执行所有旧测试。
5. **排错**：保留首次失败，只有具体新假设才再试；相同阻塞连续两次失败停止，用户要求立即停止时优先。不得降低断言、绕过审批/权限或把BLOCKED写PASS。
6. **交接**：检查diff、敏感内容及保护文件，按模板生成报告再提交。用户明确要求Draft PR可在约定分支推送，否则先批准；推送前确认自动部署联动、目标引用和单引用范围。禁止强推或附带标签。
7. **验收并停止**：ChatGPT独立审查，用户只做必要最终手机动作。任务完成即停；合并、部署、回滚和真实迁移均需单独授权。

## 风险测试矩阵

所有业务自动化只用独立本地合成数据。现有脚本可能提供可选云模式，执行前核实配置，不因文件名带test就默认安全。

|改动|复用入口与必须覆盖的证据|
|---|---|
|管理文档/门禁|management-check、self-test、diff、链接、敏感模式、保护文件；不重跑应用|
|医院/项目界面|test-phase2与相关手机尺寸流程：新建编辑、持久化、按钮与文件关联|
|同步/存储/附件/备份/权限|test-safety、test-offline、test-sync-http、test-remote-discovery中受影响完整风险回归：CAS、双方保留、幂等、原件读取失败停写、事务回滚、容量失败、重开、完整备份和隔离恢复|
|SW/资源/PWA|test-release-compat、test-pwa-upgrade及相关数据风险回归：两发布组、旧缓存、部分失败、暂停状态、离线重开及原件保留；禁止清缓存解决问题|
|构建/配置|锁定SHA、来源、白名单/尺寸/SHA、Worker与配置哈希、旧产物完整归档；旧构建不冒充新HEAD|

Playwright、浏览器与依赖必须已有或获准安装，缺失记BLOCKED。模拟浏览器、WebKit和真实iPhone分别报告；不要求用户重复已通过且未受影响的实机验收。

## 证据与报告

- PASS必须有命令、受测源码SHA、输入/步骤、预期/实际、脱敏证据；FAIL记录未满足断言；BLOCKED记录环境/权限限制；历史不可追溯继续UNPROVEN。
- 分别记录源码SHA、构建来源SHA、线上sourceCommit、Deployment ID、Version ID及流量比例；活动版本不取历史0%行代替。
- 不上传原件、备份密文、业务资料、私人绝对路径、Token或密钥。扫描有局限，不能声称完全证明不存在任意敏感信息。
- CURRENT为唯一最新交接；ROADMAP只排序；旧日期报告不改写。结束时使用任务模板，普通聊天不超过300字。报告不能把历史数量累加成当前重跑。

## 已实现自动化与未实现事项

- 管理检查：纯Node内置模块，文件/链接、变更白名单、敏感文件名/常见凭证模式/私人路径、固定基线和生产/业务保护检查，输出统一JSON。
- PR工作流：仅针对安全候选的管理相关变更；contents只读、固定checkout提交、凭据不持久化、无secrets、无部署步骤，10分钟超时。
- 工作流不是仓库强制保护；是否实际运行及是否required-check必须另行取证。首次策略阻塞不记PASS。
- 自动业务测试选择、全套浏览器CI、定时报告、ChatGPT自动独立审核连接尚未实现；当前自动报告是本地/CI标准输出，不是自动向外发送消息。

## 发布门禁

管理通过不是发布批准。发布前必须取得锁定SHA、环境、费用、可隔离恢复备份、完整版本/绑定/迁移/代码资产回退证据、必要回归和iPhone差异验收。关键项FAIL/BLOCKED则停止，不自动授权或恢复共享数据。
