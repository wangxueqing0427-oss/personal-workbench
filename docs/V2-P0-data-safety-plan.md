# V2.0 P0 数据安全实施与验收清单（草案）

状态：设计/测试计划，**尚未实现或通过测试**。仅适用于 dev/v2-p0-data-safety，严禁未经确认合并到 main 或发布。

## 安全边界
- 不读取、上传、修改用户手机上的真实业务记录或密钥。
- 不清理 Safari/PWA 存储，不重装，不执行现有“一键修复并同步”。
- 不使用生产 Cloudflare 数据做恢复试验；恢复只在隔离测试环境运行。
- 在确认本地未提交修改之前，不覆盖本地工作区。

## P0-A 完整离线备份
1. 盘点所有持久化来源：localStorage、IndexedDB（文件原件、全文索引及其他对象存储）、应用配置与 schema 版本。
2. 在用户主动触发后，导出单一可保存的完整备份包；包含 manifest（schema、导出时间、条目计数、文件字节数）及逐项校验值。
3. 导出失败必须明确报错，不能显示“备份成功”；JSON 备份要明确标注不含文件原件。
4. 不把密钥、密码、接入码写入诊断日志或 GitHub；敏感备份提供本地加密选项并明确密钥遗失风险。
5. 不上传任何个人备份到仓库。

## P0-B 隔离恢复
1. 先校验格式、版本、完整性、空间与条目数量，再显示恢复预览。
2. 默认恢复到空的隔离环境，测试文件原件可打开、全文可检索、项目及附件关联有效。
3. 在生产环境恢复前要求用户确认，先生成当前状态的安全快照；校验失败不得部分覆盖。
4. 验证重复恢复、断电/中断、存储配额不足、旧版备份兼容性。

## P0-C 云端冲突保护
1. 比较本地与云端版本、更新时间及变更标识；不以云端版本 0 推断已完成备份。
2. 双端各有新数据时禁止静默整包覆盖，提供差异预览和可撤销的合并方案。
3. 同步身份未配置时提示，不自动创建身份或发送资料。
4. 模拟离线编辑、双端并发、重复同步、网络中断和身份失效。

## 测试门槛
- 单元/集成测试：空数据、文字、图片、二进制附件、中文文件名、大文件、多文件、损坏备份、配额不足。
- 浏览器回归：iPhone Safari、主屏幕 PWA、Windows 浏览器；刷新、关闭重开、离线、升级后数据保留。
- 每项记录步骤、结果和失败证据；未实测不得标记通过。
- 代码提交仅限开发分支；测试通过并经用户明确批准后才考虑发布。

## 当前阻碍
Codex 本地终端/电脑界面工具曾启动失败；本地目录、未提交修改、实际手机数据备份尚未核实。可以先在 GitHub 开发分支进行非生产代码和测试设计，但不得宣称恢复验证完成。
