# 个人工作台 V2.0｜独立预览安全评审及发布门禁（2026-11-13）

## 结论与范围

- **现阶段定位**：仅合成资料、完全独立的 Cloudflare Workers Free 预览环境，不支持真实医院、资产、联系人及个人数据录入。
- **不等于正式验收**：自动化 Chromium 与 WebKit 测试不能替代真实 iPhone Safari / 主屏幕 PWA 验收。
- **不包含的行为**：未部署正式 V1.5.7、未合并 `main`、未部署原 V2 staging、未开通付费套餐、未迁移历史用户记录。
- **操作权限**：仅在 `dev/v2-preview-isolated-20261111` 上新建/修改预览构建、预览隐私模块、预览工作流及合成测试。Cloudflare Preview Worker 单独部署，所有远端合成测试采用可撤销的临时凭据。

## 已实施的安全改进

1. **明确本机模式**：预览网站尚未接入测试云端身份时，显示「本机演示模式 · N项未上传 · 未接入测试云端，请勿录入真实资料」；不得将「待同步」误称作「已备份」。
2. **发版与资源对应**：正式发布动作仅针对指定的 Preview Worker；19个生成资源经过 SHA-256 校验，发版后同一 GitHub Actions 验证云端 `sourceCommit` 与实际工作流提交 SHA 完全一致；独立 Worker/DO/测试数据集有配置校验。
3. **可选的本机 PIN 界面遮挡**（`v2/preview-privacy.js`）：默认**关闭**，必须在测试站点由用户自主启用；先保存一个仅展示一次的128位随机恢复码，才允许设置6–12位 PIN。PIN 使用随机盐与 PBKDF2-SHA256 210000次派生，仅保存验证摘要；恢复码只保存加盐校验摘要，不保存明文。
4. **隐私遮挡覆盖路径**：开启后页面在首帧绘制前设置锁定状态；锁住业务首页、根路径 `/p0.html` 备份入口以及按版本号发布的 P0 备份入口；模拟网页后台切换时立刻遮挡，模拟连续90秒无操作后遮挡；错误 PIN 5次触发递增冷却；正确 PIN 解锁/关闭或使用单独保存的恢复码解锁，均不能删除原始记录、附件和同步队列。
5. **完整原件测试**：AES-GCM 云端测试用具备真实 512KiB 合成附件、分片和冲突的自动化用例，重复/损坏分片不可覆盖旧记录，两个独立浏览器合并时保留双方记录与原件。备份测试对损坏的加密备份拒绝恢复，只允许恢复到新建隔离数据库。

## 严格限制与阻止正式发布的项目

- **隐私 PIN 目前只是一层本机界面遮挡**，并不加密 IndexedDB、浏览器文件原件或离线缓存；不能抵御同源恶意脚本、开发者工具、清理网站数据及恶意设备访问。**不得把它宣传为 Face ID 已完成，也不得让它替代生产级本地加密。**
- **Face ID / 平台生物识别 + 安全的 PIN 备用方案尚未完成。** 正式版需先确定符合 iOS Safari/PWA 支持性的 Passkey/WebAuthn、设备密钥或其他操作系统验证方案，并对密钥恢复、换机、丢失设备、数据静态加密进行专项验收。
- **长期安全的手机云端验收身份入口尚未完成。** GitHub CI 用的 `TEST_TOKEN` 在每轮测试之后自动删除并核验撤销；普通预览网站的待同步队列因此不能作为云端已保护的证据。
- **iPhone Safari 与添加到主屏幕的实际存储隔离、离线缓存升级、后台生命周期、多设备合并交互**尚需最终真人设备验收；WebKit模拟测试不能替代。
- **V1.5.7生产资料与V2.0历史资料合并、备份快照恢复和迁移**还没有获得授权，也没有实施。任何正式发布或接入真实数据必须单独获得用户明确批准。
- **预览分支与 `main` 当前无法通过GitHub compare建立共同祖先**（compare API返回404）；后续若需正式集成，必须另做无破坏的版本映射、备份核对和并行运行方案，不得擅自强行合并。
- 用户此前生成的 Cloudflare 专用部署令牌设置为7天有效；约2026-11-20前后到期，过期后后续云端部署需用户通过官方界面重新授权，**当前无需参与**。
