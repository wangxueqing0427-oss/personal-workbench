# 同步后端隔离验收

新增sync-lab.cjs及test-sync-http.cjs。不是生产Cloudflare后端，也不是iPhone同步适配器。

本地HTTP仅绑定127.0.0.1，需要每次测试随机生成的鉴权令牌；保存对象为AES-GCM加密合成业务记录及附件。写入在单进程队列中检查expectedRevision和expectedHash，写新临时文件、flush后重命名，再返回成功。接口限制20MB。本工具不应部署：无多进程锁、无生产身份体系、无生产容量/配额/监控保障。

测试结果以sync-http-results.json为准；首次13项，后续补测离线期间另一端编辑及传输哈希校验。

- 无令牌拒绝请求。
- 两个HTTP客户端并发提交同一基线，一个成功、一个409；失败端保留副本，不自动合并。
- 停止服务器模拟不可达，本地副本可继续编辑。
- 重启服务器读取合成测试版本，恢复联网后先读取当前版本再提交。
- 旧请求重试返回409，不重复追加；不是自动幂等成功应答。
- 项目附件ID关联、原件逐字节、损坏密文拒绝校验通过。
- 离线旧基线重连遭遇另一端新版本时返回409；显式核对合并的测试保留双端进展。没有实现用户界面的自动合并。
- 篡改传输哈希返回400，持久版本不改变。

测试只写系统新建临时目录的合成文件，没有删除目录。密钥、令牌仅在测试进程生成，未写入仓库。进程退出后这些测试密文不作为可恢复的用户备份。
